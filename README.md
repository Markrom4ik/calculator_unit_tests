# Calculator Unit Tests

## Описание проекта

Проект представляет собой простой калькулятор на языке Python и набор Unit-тестов для проверки его работы.

Калькулятор поддерживает четыре арифметические операции:
- Сложение (`+`)
- Вычитание (`-`)
- Умножение (`*`)
- Деление (`/`)

При попытке деления на ноль программа вызывает исключение `ZeroDivisionError`.

## Структура проекта

- `calculator.py` — исходный код калькулятора.
- `test_calculator.py` — Unit-тесты.
- `.gitignore` — список файлов, которые Git не должен отслеживать.

## Запуск калькулятора

Для запуска программы необходимо выполнить команду:

```bash
python3 calculator.py
```

## Запуск Unit-тестов

Для запуска всех тестов используется команда:

```bash
python3 -m unittest -v
```

## Результаты тестирования

Всего реализовано 9 Unit-тестов, проверяющих:
- Сложение положительных и отрицательных чисел.
- Вычитание с положительным и отрицательным результатом.
- Умножение обычных чисел и умножение на ноль.
- Деление без остатка и с остатком.
- Обработку деления на ноль.

Все 9 тестов успешно пройдены.
